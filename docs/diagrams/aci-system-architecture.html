3. Routing pipeline (§14) — luồng chính của platform

Mỗi stage phát trace data. Client nhận bundle (0–5 skills, pin version + digest), thực thi local, rồi báo lại outcome + evaluation — vòng feedback của routing.

Bundle rỗng = success hợp lệComposer không bao giờ nhét skill có độ tin cậy thấp (ADR-008) — 0 item là một kết quả đúng.
Reranker không rescue đượcHeuristicReranker chỉ xếp lại hạng ứng viên đã eligible — không thêm/rescue nội dung (ADR-009). Embed + rerank chỉ trên trusted metadata; raw SKILL.md không bao giờ vào prompt (§16.1).
Embedder hoán đổi đượcACI_EMBEDDER=hashing (offline, mặc định CI) | fastembed (semantic 384d — dev-31 recall 0.712).

4. Ingestion & governance — từ nguồn tới production

Re-ingest giống hệt = idempotent; cùng version khác content = CAPABILITY_ALREADY_EXISTS. Production luôn cần con người (ADR-012/013) — automation tối đa chỉ tới staging/canary.

Unknown license chặn mặc định (§24)Không đoán được license → quarantined, không vào catalog/routing. Human override qua review_queue approve-license — append-only, không xoá finding tự động.
Acquisition era — FROZEN (ADR-013)Crawler/scout/refinery/judges/canary vẫn mounted nhưng ngừng mở rộng: automation chỉ được đẩy tới staging + canary (split deterministic), production human-only. weekly_cycle.sh đã verify end-to-end.

5. HarnessKernel — agent execution plane (ADR-014, UNFROZEN 2026-09-30)

Vòng thực thi verifier-gated: model hành động → authority + guardrails chặn trước/sau → tool chạy trên bản copy workspace (data/agent-runs/) → pytest quyết định → fail thì repair turn (mũi tên đứt quay lại model). 3 run thật đầu tiên: 3/3 verifier-gated succeeded (glm-5.3, pytest làm verification).

Kernel managers (src/aci/runtime)

Honest-fail, không sandboxKhông cấu hình gateway (ACI_AGENT_MODEL_BASE_URL rỗng) = fail caller-visible, không bao giờ im lặng dùng model mặc định. Tool chạy dưới user của server — ACI_AGENT_PROCESS_PREFIXES là whitelist lệnh; SandboxWorkspace là non-goal v2.
Exposure gateACI_AGENT_RUNS_TOKEN đặt = mọi route cần Bearer token (401 nếu sai); rỗng = unauthenticated + warning khi khởi động. Guardrails chuẩn (ShellInjection, PathTraversal pre-tool; SecretLeak post-tool) là tuyến phòng thủ hai sau authority + workspace path checks.
Gap đã ghi nhận (chưa làm)Runs RAM-only (chưa có bảng DB — restart mất); CapabilityRuntime chưa wire trên REST path (agent chạy WITHOUT registry skills); không resume từ checkpoint; tool error chưa qua RecoveryManager (không retry-block cho tool non-idempotent); approval flow chưa wire (REQUIRE_APPROVAL → denied); command_passed_after_last_change chấp nhận MỌI lệnh exit-0 (không chỉ test); không sandbox (theo thiết kế v2). H-bench runner đã MET (run_hbench.py — round 1 xong).

9. Đo lường đã ghi (§34 caveat: n nhỏ, author fixtures — directional)

Tỷ lệ chấp nhận (acceptance) theo arm — %

Nguồn: data/proof-loop/*.json (§80, 7 rounds) + data/hbench/hbench-20260930-232757.json (H-bench round 1, glm-5.3, 8 fixtures multi/long, max_turns=12). Hai thí nghiệm khác nhau — không so trực tiếp K/N với A/E.

33/33§80: A = E (không delta outcome)
21/24 vs 18/24H-bench r3 (fair): K ≥ N mọi case — edge nhỏ, nhất quán
0.00false_success cả 48 runs (glm-5.3 không claim sai)
40s vs 50swall K vs N r3 — không chênh lệch chi phí đáng kể
Đọc kết quả thế nào§80 (7 rounds, n=33): không value nào đo được trên single-bug acceptance — model giải được naked. H-bench 3 rounds là bài học phương pháp: vòng 1 (K 0.75 vs N 0.50) từng được ghi là "delta dương đầu tiên" — đã RÚT LẠI (N thiếu system prompt — prompt artifact); vòng 2 đảo chiều nhưng thước đo hai arm khác nhau (yardstick artifact); vòng 3 fair hoá: K 0.88 (21/24) vs N 0.75 (18/24) trên cùng thước tests_pass_at_end, K ≥ N MỌI case (3 thắng, 5 hoà, 0 thua) — edge nhỏ, nhất quán, chưa significant ở n=24 (z≈1.1), kèm bảo đảm cấu trúc 0 false-success. Trục tiếp theo = model yếu hơn (H008 chưa demonstrate ở tier glm-5.3).

Sơ đồ vẽ từ code thật (src/aci/**, wiring.py, main.py) + hồ sơ đo lường trong data/ — không phải từ tài liệu suông. Mọi con số có nguồn ở AGENTS.md hoặc file JSON tương ứng.
